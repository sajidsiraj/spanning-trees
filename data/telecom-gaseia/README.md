# Telecom backbone data

These files are the pairwise comparison matrices from the rural telecom
backbone case study used in the manuscript.

The judgements were collected and published by Gasiea, Emsley and
Mikhailov (2023), "Rural telecommunications infrastructure selection
using the analytic network process," Journal of Telecommunications and
Information Technology. They are reused here, with citation, to
reproduce and validate the spanning trees analysis on real published
data. They are not data we collected ourselves.

- `pc-telecom.xlsx`: the pairwise comparison matrices, as elicited in
  the original study.
- `TelecomExample.pwc`: the same problem in PriEsT's own XML format.
- `TelecomExample-random.csv`: a PriEsT random-walk sample output,
  used to check our own random-walk estimates against an independent
  implementation.
